🫧 말랑말랑 퀴즈 놀이터 · 선생님 안내서

인쇄해서(Ctrl+P) 책상에 두고 쓰셔도 좋아요. 앱 화면으로 돌아가려면 여기를 눌러 주세요.

① 처음 시작하기 (딱 한 번)

  1. 앱 주소를 열고 교사용을 눌러요.
  2. 새 PIN 만들기를 눌러 숫자 4자리를 두 번 입력해요. 이 PIN은 선생님의 아이디예요. 같은 PIN으로 들어오면 내가 만든 방만 보여요. 다른 선생님은 다른 PIN을 만들면 서로의 방이 섞이지 않아요.
  3. 방 만들기에서 방 이름과 모둠 수(1~6)를 정해요. 6자리 방 코드와 QR이 나와요.
⚠️ PIN은 비밀번호가 아니라 아이디예요. 남에게 알려 주면 그 사람도 내 방을 볼 수 있어요. 학생에게는 PIN 대신 방 코드/QR만 알려 주세요. PIN을 잊어버리면 방을 찾을 수 없으니 꼭 적어 두세요.

② 학생 들어오기

  • 학생은 태블릿으로 QR을 찍거나, 앱 주소에서 방 코드를 입력해요 → 닉네임 → 모둠 고르기.
  • 실명 대신 별명을 쓰게 해 주세요. 같은 닉네임은 한 방에 하나만 쓸 수 있어요. 학생이 나갔다 다시 들어오면 점수와 기록이 그대로 남아요.
  • 교사 화면 [학생] 탭에서 접속 현황을 보고, 모둠을 바꿔 줄 수 있어요.
  • 이름을 잘못 쓴 학생은 [학생] 탭에서 그 학생 이름 바로 옆의 [퇴출] 버튼을 눌러요. 확인창에서 [퇴출하기]를 누르면 학생 태블릿이 입장 화면으로 돌아가고, 올바른 이름으로 다시 들어올 수 있어요.
    • 퇴출하면 그 학생의 자료가 모두 완전히 삭제돼요(되돌릴 수 없어요): 접속 기록과 공부하기 점수, 학생이 직접 낸 단어와 문제(승인된 것도 포함)가 모두 지워지고, 공부하기·게임에 쓰는 목록에서도 바로 빠져요.
    • 선생님이 나눠 준 배정 카드를 그 학생이 채웠다면, 단어 글자만 남기고 학생이 쓴 뜻·예문·그림은 지워져서 빈 카드(담당자 없음)로 돌아가요. 다른 학생에게 다시 나눠 줄 수 있어요.
    • 같은 이름으로 다시 들어오면 아무 기록 없이 처음부터 시작해요(점수 0점, 낸 단어·문제 0개).
    • 참가자 확인이나 게임 중에는 퇴출할 수 없고, 이때는 아무 자료도 지워지지 않아요. 확인을 [취소]하거나 게임이 끝난 뒤에 해 주세요.

③ 단어 모으기와 승인

  • 학생이 단어 내기(단어·뜻·그림 주소·예문) 또는 문제 내기를 해요. 같은 단어는 저장되지 않아요.
  • 선생님은 [단어·문제] 탭에서 승인 / 수정 / 삭제해요. 승인된 말만 공부하기와 게임에 쓰여요.
  • 엑셀로 내려받기: [단어·문제] 탭의 📥 엑셀로 내려받기를 누르면 학생들이 만든 단어 카드 표(.xlsx)가 내려받아져요. 모둠 → 만든 학생 → 단어 순으로 정리되고, 단어·유형·뜻·예문·그림 주소·상태·낸 시각이 들어 있어요. 뜻이 비어 있는 “작성 전” 카드는 빠져요. 첫 줄의 필터 버튼으로 모둠이나 상태(승인됨 등)만 골라 볼 수 있어요. 서버를 쓰지 않아서 사용량(읽기·쓰기)은 0건이에요.
  • 한꺼번에 등록: 한 줄에 하나씩 붙여 넣고 소탐대실, 속담처럼 쉼표 뒤에 종류(단어/관용 표현/속담)를 쓸 수 있어요. 등록한 카드는 랜덤 배정으로 학생에게 나눠 주면 학생이 뜻을 써서 제출해요.
  • 승인·수정·삭제를 하면 3초 뒤에 학생용 묶음이 자동 저장돼요(맨 위에 “저장됨” 표시).

④ 공부하기 · 단어 카드 · 순위판

  • 학생 홈의 공부하기는 승인된 말로 자동 퀴즈(4지선다/단답형)를 내고, 맞히면 개인 점수가 올라가요(5문제마다 저장).
  • 단어 카드는 앞면(뜻·그림·예문), 뒷면(단어) 플래시카드예요.
  • 교사 [학생] 탭의 개인 점수 순위 TV에 띄우기를 누르면 발표 화면(TV)에만 순위가 나와요. 개인 점수 초기화로 모두 0점으로 되돌릴 수 있어요.

⑤ 게임 진행하기 (교사 화면의 [게임] 탭)

  1. 참가자 확인 시작을 눌러요. 학생 화면이 켜져 있으면 약 10초 안에 자동으로 “확인됨”이 돼요. 화면이 꺼진 태블릿은 “응답 없음”에 나오니, 체크하면 참가자에 넣을 수 있어요.
  2. 게임을 고르고 설정(시간·문제 수 등)을 정한 뒤 게임 시작!
  3. 발표 화면(TV)은 [발표 화면] 버튼으로 새 창을 열어 TV에 띄워요. 전체화면 버튼도 있어요.
  4. 끝나면 최종 결과가 학생 태블릿과 TV에 같이 나와요. 선생님이 [결과 닫기]를 누르면 처음 화면으로 돌아가고 임시 기록은 자동으로 지워져요.
  5. 무슨 일이 있어도 [게임 중단]을 누르면 정리하고 처음 상태로 돌아가요.
게임방법점수
🎬 라이브 퀴즈모두에게 같은 문제를 내요. 4지선다 또는 단답형. 맞힌 뒤 카드 뽑기 투표(점수 2배/무효/+10/−10 중 뽑을지 함께 정해요)반 전체 점수 하나(음수 가능)
🙋 전체 스피드 퀴즈반에서 한 명씩 돌아가며 말·몸짓으로 설명, 나머지가 정답 입력. 패스 가능맞히면 반 +1점
⚡ 모둠 스피드 퀴즈모둠별로 동시에 진행. 설명자 화면엔 단어만, 나머지는 입력창맞히면 모둠 +1점
🎨 텔레스트레이션그림 → 글 → 그림 → 글 … 이어 가며 마지막 친구가 제시어를 맞혀요. 여러 판 가능정답 체인당 모둠 +1점
💡 모둠 게임은 모둠에 3명 이상 모여야 참여해요. 모둠을 고르지 않은 학생은 전체 게임에만 참여해요.

🎬 라이브 퀴즈의 TV 화면

  • 정답자 게이지: 학생들이 답을 내는 동안 TV에 맞힌 친구 수가 막대로 차올라요(예: 맞힌 친구 8 / 28명). 전원이 맞히면 막대가 금색으로 바뀌어요.
  • 이름 목록: 정답을 공개하는 순간부터 TV에 🎉 맞힌 친구와 🤔 아쉬운 친구의 이름이 나와요. 시간 안에 내지 못한 친구는 아쉬운 친구 쪽에 회색으로 나와요. 답을 쓰는 동안에는 이름이 나오지 않아요.
  • 가리기: 게임 시작 화면의 [TV 이름 목록]에서 처음 상태(모두 보이기 / 맞힌 친구만 보이기 / 이름 가리기)를 고를 수 있어요. 게임 중에는 진행 카드 아래 👀 맞힌 친구 이름 / 아쉬운 친구 이름 / 이름 모두 가리기 버튼으로 바로 바꿀 수 있어요. 가려도 인원수는 TV에 보여요. 가림 상태는 다음 문제에도 이어져요.
  • 틀린 친구의 이름이 TV에 나오는 것이 부담스러운 반이라면 “맞힌 친구만 보이기”로 시작해 보세요.

수업 전 점검표

  • 교사 컴퓨터가 인터넷에 연결되어 있고, 게임 중에는 교사 창을 닫거나 최소화하지 않기 (타이머와 진행을 이 창이 맡아요).
  • 승인된 말이 충분한지 확인(4지선다는 같은 종류 4개 이상, 스피드 퀴즈 3개 이상, 텔레스트레이션은 모둠 인원 합 이상이면 좋아요).
  • 그림 문제는 학생이 낸 https 그림 주소가 열려야 해요. 열리지 않으면 자동으로 다른 문제로 바뀌어요.

⑥ 문제가 생겼을 때

이런 일이이렇게 해요
학생이 이름을 잘못 입력했어요[학생] 탭에서 그 학생 이름 옆의 [퇴출]을 눌러요. 그 학생의 점수·단어·문제가 모두 지워지고, 학생은 올바른 이름으로 다시 입장하면 돼요.
학생이 새로고침하거나 태블릿이 잠깐 꺼졌다 켜졌어요자동으로 같은 방·같은 게임으로 돌아와요. 점수와 기록은 그대로예요.
게임 중 교사 창을 닫았거나 컴퓨터가 멈췄어요같은 PIN으로 다시 들어가 방을 열면 이어서 진행할 수 있어요. 다른 창에서 열렸다면 진행 카드의 [진행 넘겨받기]를 눌러요.
참가자 확인 중에 다른 탭에 갔다가 돌아왔어요[게임] 탭으로 돌아오면 확인 결과와 게임 고르기 화면이 그대로 이어져요. 혹시 멈춘 것 같으면 위쪽 안내 줄의 [취소]를 누르고 [참가자 확인 시작]부터 다시 해요.
설명자 학생이 자리를 비웠어요 (스피드 퀴즈)진행 카드의 [설명자 건너뛰기]를 눌러요.
화면 위에 “연결이 끊겼어요” 안내가 나와요와이파이를 확인해 주세요. 다시 연결되면 자동으로 이어져요.
게임이 멈춘 것 같아요[게임 중단] 후 다시 [참가자 확인]부터 시작해요.
[게임] 탭이 비어 있거나 ⚠️ 오류 카드가 떠요카드의 [다시 시도]를 눌러 보세요. 그래도 같으면 [최신 파일 다시 받기]를 눌러요. 오류 카드의 글(또는 사진)을 보내 주시면 원인을 바로 찾을 수 있어요. 급하면 위쪽 안내 줄의 [취소] 후 다시 시작해요.
GitHub에 새 파일을 올렸는데 화면이 그대로예요올린 뒤 1~2분 기다린 다음 Ctrl+Shift+R(맥은 ⌘+Shift+R)로 새로고침해요. 방 화면 맨 위 “PIN … · v2.5-final”과 화면 맨 아래의 글자가 v2.5-final인지 확인하세요. 숫자가 다르면 아직 예전 파일이에요. 화면 위에 “새 버전이 올라와 있어요”라는 안내가 뜨면 같은 방법으로 새로고침하면 돼요.
“데이터베이스 규칙이 게시되지 않았어요” 안내가 나와요Firebase 콘솔 → Firestore Database → 규칙 탭에서 규칙이 allow read, write: if true; 상태로 게시되어 있는지 확인해요. “테스트 모드”로 만든 규칙은 30일 뒤에 저절로 막혀요. 이때는 날짜 조건 대신 if true로 바꿔서 게시하면 돼요.
“오늘 사용 한도에 도달했어요” 안내가 나와요무료 사용량을 다 쓴 거예요. 다음 날(한국시간 오후 4~5시경 초기화)에 다시 쓸 수 있어요.

⑦ 무료 사용량 알아 두기

이 앱은 Firebase 무료 요금제(Spark)를 써요. 하루 한도는 읽기 50,000 · 쓰기 20,000 · 삭제 20,000건이에요. 한도를 넘어도 요금이 청구되지는 않고, 그날은 앱이 일시적으로 멈춰요.

학생 28명, 4개 모둠 기준 사용량이에요. 진짜 학생 4명 + 가상 학생 24명으로 직접 돌려서 잰 값이고, 가상 학생은 사람보다 빠르게 풀기 때문에 넉넉하게 잡은 값(상한)이에요. 읽기는 “다른 사람의 화면이 바뀌어서 내 화면에 전해지는 것”도 한 건씩 세요.

⑧ 보안과 개인정보 (꼭 읽어 주세요)

  • 이 앱은 로그인 없이 쓰도록 만들었어요. 방 코드를 아는 사람은 누구나 들어올 수 있어요. 방 코드는 학생에게만 알려 주세요.
